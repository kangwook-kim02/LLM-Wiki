# Skill: ingest

## 입력

| 변수 | 설명 | 예시 |
|------|------|------|
| `$SOURCE` | 사용자 메시지에서 추출한 파일명 | `langchain-docs.pdf` |

---

## 절차

### Step 1 — 현황 파악

```
MCP: wiki_list()
→ 기존 페이지 슬러그 전체 목록 확인
→ 신규 생성할 페이지와 중복 여부 체크
```

### Step 2 — 소스 읽기

```
MCP: raw_read($SOURCE)
→ 전체 내용 파악
→ 핵심 개념, 프레임워크, 패턴 식별
→ 생성할 페이지 목록 초안 작성
```

### Step 3 — 소스 요약 페이지 생성

```
MCP: wiki_write("sources/{소스슬러그}", content)
```

페이지 형식은 `docs/wiki-schema.md` 4번 항목 참조.

### Step 4 — 개념/프레임워크/패턴 페이지 생성 또는 업데이트

각 식별된 항목에 대해:

```
MCP: wiki_read("{카테고리}/{슬러그}")
→ 기존 페이지 있으면: 내용 보강 후 wiki_write로 업데이트
→ 없으면: 신규 wiki_write로 생성
```

페이지 유형별 위치:
- 기술 개념 → `concepts/{슬러그}`
- 프레임워크/도구 → `frameworks/{슬러그}`
- 아키텍처 패턴 → `patterns/{슬러그}`

### Step 5 — 인덱스 업데이트

```
MCP: wiki_read("index") → 신규 페이지 항목 추가
MCP: wiki_write("index", 업데이트된_내용)
```

### Step 6 — 작업 이력 기록

```
MCP: wiki_read("log") → 상단에 새 항목 추가
MCP: wiki_write("log", 업데이트된_내용)
```

이력 형식:
```
## YYYY-MM-DD — {소스 제목} 인제스트
- 생성: {페이지 목록}
- 업데이트: {페이지 목록}
- 소스: [[sources/{슬러그}]]
```

---

## 원칙

- 한 소스당 최소 5개 이상 페이지 생성 또는 업데이트
- `raw/` 파일은 절대 수정하지 않는다
- 기존 페이지를 덮어쓸 때 기존 내용 삭제 금지 (보강이 원칙)
- 출처 없는 주장 작성 금지
