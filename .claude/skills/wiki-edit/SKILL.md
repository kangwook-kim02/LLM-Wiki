# Skill: wiki-edit

## 절차

### Step 1 — 대상 페이지 확인

```
MCP: wiki_search("{페이지명 키워드}")  → 정확한 슬러그 확인
MCP: wiki_read("{슬러그}")             → 현재 내용 전체 읽기
```

페이지가 없으면 사용자에게 신규 생성 여부 확인 후 진행.

### Step 2 — 편집 실행

복잡한 편집은 변경 계획을 먼저 사용자에게 보여주고 확인 후 진행.

```
현재 내용 수정 (인메모리)
→ frontmatter의 updated 날짜 갱신
MCP: wiki_write("{슬러그}", 수정된_전체_내용)
```

`wiki_write`는 전체 내용을 덮어씁니다. 부분 수정도 전체 파일을 다시 씁니다.

### Step 3 — 연관 페이지 업데이트 (필요 시)

```
MCP: wiki_search("{영향받는 개념 키워드}")
→ 연관 페이지 확인 및 필요 시 업데이트
```

### Step 4 — 이력 기록

```
MCP: wiki_read("log")
MCP: wiki_write("log", 이력_추가된_내용)
```

---

## 원칙

- 기존 정보를 삭제하지 않는다 (명시적 삭제 요청 제외)
- YAML frontmatter 항상 유지
- 편집 후 변경 내용을 사용자에게 요약 보고
