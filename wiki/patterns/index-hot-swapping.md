# Index Hot-Swapping (인덱스 핫 스와핑)

## 문제 상황
세계는 끊임없이 변하지만, parametric-only 언어 모델(T5, BART 등)은 세계 지식을 업데이트하려면 전체 재학습이 필요하여 비용이 매우 크다.

## 해결 방법
RAG의 non-parametric memory(검색 인덱스)를 교체하여 모델 재학습 없이 세계 지식을 업데이트한다.

구체적인 절차:
1. 새로운 문서 코퍼스 준비 (예: 최신 위키피디아 덤프)
2. DPR 문서 인코더로 새 문서 임베딩 생성
3. FAISS 인덱스 재구축
4. 모델의 non-parametric memory 컴포넌트를 새 인덱스로 교체
5. 모델 파라미터는 변경 없음

## 구현 예시
RAG 논문의 실험에서 2016년 위키피디아 덤프와 2018년 덤프를 교체하여 세계 리더 정보 업데이트를 검증했다:
- 2016년 인덱스 + 2016년 리더 질의: 70% 정확도
- 2018년 인덱스 + 2018년 리더 질의: 68% 정확도
- 불일치(2018 인덱스 + 2016 리더): 12% 정확도

## 트레이드오프
- 장점: 재학습 비용 없이 지식 업데이트 가능
- 장점: 도메인 특화 코퍼스로 교체하여 특정 분야 전문화 가능
- 단점: 문서 인코더가 고정되어 있어, 새 코퍼스의 특성이 크게 다르면 성능 저하 가능
- 단점: 인덱스 구축(임베딩 생성)에 시간과 컴퓨팅 자원이 필요
